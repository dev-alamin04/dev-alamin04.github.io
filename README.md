## 🚀 About The Project

This is my personal developer portfolio, designed to showcase my skills, experience, and projects in a highly interactive and engaging way. The portfolio features a unique, custom-built **animated interactive aquatic background** (Golden Betta Fishes) using HTML5 Canvas and Inverse Kinematics, delivering a premium user experience.

### ✨ Key Features

- **Interactive Aquatic Background:** Beautiful golden fishes that dynamically swim around and follow your cursor using advanced mathematics.
- **Smooth Animations:** Powered by ramer-motion for buttery smooth scroll reveals and page transitions.
- **Modern UI/UX:** Glassmorphism, neon glows, and dark mode aesthetics.
- **Fully Responsive:** Perfectly optimized for mobile, tablet, and desktop views.
- **Fast & Performant:** Built on Vite for lightning-fast HMR and optimized production builds.

## ⚙️ Getting Started

To run this project locally, follow these simple steps:

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

1. **Clone the repository**
   ``bash
   git clone https://github.com/dev-alamin04/dev-alamin04.github.io.git
   ``

2. **Navigate to the project directory**
   ``bash
   cd dev-alamin04.github.io
   ``

3. **Install dependencies**
   ``bash
   npm install
   ``

4. **Start the development server**
   ``bash
   npm run dev
   ``

5. Open your browser and visit http://localhost:5173

---

## 📝 Scripts

- 
pm run dev: Starts the Vite development server.
- 
pm run build: Builds the app for production.
- 
pm run preview: Previews the production build locally.
- 
pm run deploy: Deploys the build to GitHub Pages.
